# Quest Compositor Lab

This repository owns neutral shader examples, inert host selection tooling and
its single `.planning/CONTINUATION.md`. Source-only checks do not prove native
loading, headset rendering, scanout or wearer acceptance.

Keep private effects, vendor binaries, raw device evidence, credentials and
machine paths absent from every public commit. Explicitly inventory admitted
files and their origin/license in `docs/PROVENANCE.json`. Do not copy uncertain
starter sources. Generic audio Java sources remain owned by the pinned Quest
supplier; no second mutable copy belongs here.

Run `python -m unittest discover -s tests -v`,
`python tools/check_public_boundary.py`, `git diff --check` and the configured
shader compile fixture before a source milestone. Keep generated results under
ignored `local/`. No tool in this repository applies device properties.
For capture-sink changes also run its `run_tests.py --suite all`, compile the
Android source against an explicitly selected SDK jar, and compile/run the inert
identity example. Java admission is limited to the declared capture namespace
and exact identity example; every file still needs an explicit provenance row.
The sink module owns its sink ABI/app-side accounting. The nested controller
owns neutral finite orchestration source only; real firmware drivers, durable
external custody, native image/queue lifetime and global restart admission remain
consumer-owned. For controller changes run its dedicated headless runner against
the exact sink inventory and pinned SDK; do not rerun unchanged sink suites.
Honor any active no-foreground constraint: run headless tests and explicitly
reuse only byte-unchanged shader/compiler evidence rather than launching probes.

Workstream integrator selects branches/remotes and stages scoped files. Other
workers own assigned files only and must preserve other workers' changes.
All delegated implementers/reviewers use gpt-6.1-sol at high or xhigh reasoning.
No ADB, headset operations or long shared builds in this source-only slice.
