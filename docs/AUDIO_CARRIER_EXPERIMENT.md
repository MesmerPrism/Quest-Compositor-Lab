# Optional optical carrier experiment

The existing experiment has abrupt gain changes. A fixed byte value 128
removed reported jumps in its private comparison. That implicates a path
difference; it does not establish a cause, persistent shader state or a repair.
Tearing and grid invisibility are also unresolved. No private effect variants
or appearance receipts are exported here.

First compare a packet encoding constant 128 with a fixed-128 shader branch,
holding source scene, time, graph and all controls equal. Check quantization,
CRC/flags/nonce, per-eye spatial sampling, stale behavior and scaling. Preserve
raw, source, decoded and applied values with their actual source lineage.

Only after constant equivalence, try a source-anchored ramp/step. Keep capture
timestamps immutable; separate source, delivery and draw age. Test source
silence, stop, UI stall, expiry, sequence wrap and one-eye sampling. Derived
application values remain distinctly labelled and retain capture time; they
are not interchangeable with raw microphone observations.

Discarded intermediate attachments provide no persistent shader history.
Any temporal smoother must have explicit host-owned state, source-time reset
and expiry behavior and remain a measured hypothesis. Direct in-app typed
audio/LUT parameters need none of this carrier and proceed independently.

The checked-in vector tests cover the pinned wire bytes only. Device optical
decoding, native adoption, scanout, gain smoothness and wearer acceptance are
open. A later trial needs admitted exact source/target, owned stage, fresh
construction, restoration and actual visual evidence.
